# Swedish Career Assistant

مشروع من **RAED SHIHAB — رائد شهاب**.

An AI-powered assistant to help newcomers find jobs in Sweden by building CVs, searching for jobs, writing cover letters, and preparing for interviews. Now available in English and Arabic.

## الروابط


- [الكود وإعدادات هذا المشروع](https://github.com/arabsweden/swedish-career-assistant)
- [مشاريع رائد وروابط التواصل](https://linktr.ee/raedshihab)

روابط التشغيل الخارجية والكود في هذا المستودع قد تتحدث بصورة مستقلة؛ تعديل أحدهما لا يعني مزامنة الآخر.

## التشغيل المحلي

```bash
npm install
npm run dev
```

وظائف الذكاء الاصطناعي تحتاج إعدادًا منفصلًا؛ لا تُضمّن مفتاح API في ملفات المتصفح المنشورة.

## البناء والتحقق

```bash
npm run build
```
